# UniShare

UniShare is a collaborative academic summary platform for Israeli university students.

The platform allows students to browse, upload, and share academic summaries from different Israeli universities and academic fields.

## Project Status

This repository currently includes the initial UI screens of the project, created as part of the UX/UI planning stage.

The project is currently built with static HTML, CSS, and JavaScript.  
In the next stages, it will be developed into a full-stack application.

## Screens

- Home Page — `index.html`
- Login / Register Page — `login.html`
- Browse Summaries Page — `browse.html`
- Upload Summary Page — `upload.html`

## Current Features

- Modern responsive navigation bar
- Home page with project explanation and call-to-action buttons
- Login and registration forms with basic validation
- Browse summaries page with filtering by university, subject, and keywords
- Upload summary form with file selection simulation
- Interactive JavaScript for tabs, filtering, saving, and upload feedback
- Clean blue/teal design style

## Setup Instructions

To run the current UI version locally:

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` with Live Server.
4. Use the navigation bar to move between the pages.
